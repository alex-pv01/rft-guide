# Contributing

rft is developed in the open at
[alex-pv01/rft-plugin](https://github.com/alex-pv01/rft-plugin). Changes to the plugin's code are
welcome as pull requests there.

How to run the plugin from a clone, how to run its tests and where each part of the code lives
are in
[`CONTRIBUTING.md`](https://github.com/alex-pv01/rft-plugin/blob/main/CONTRIBUTING.md), in the
plugin's repository. It names source files, so it is kept beside them and not here.

This guide has a repository of its own,
[alex-pv01/rft-guide](https://github.com/alex-pv01/rft-guide). A correction to a page is a pull
request there; its README says how to build the site.
